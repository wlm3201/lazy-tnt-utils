# Lazy TNT Utils（弱加载 TNT 可视化）

简体中文 | [English](README_EN.md)

一个 Minecraft 的 Fabric mod，在弱加载区块中准确显示 TNT 与物品实体的真实状态，主要面向弱加载 TNT 装置开发。支持 26.1.2、26.2 与 26.3。

## 工作原理

弱加载区块里服务端不会 tick 实体，即 TNT 既不会递减引信也不会自行运动，但客户端仍照常本地模拟，导致客户端把 TNT 引信跑完，提前爆炸并消失。

### 本mod:

- 客户端：单人游戏把受支持实体每刻修正为集成服务端真实状态，多人游戏则取消客户端本地模拟，从而 TNT 不会提前爆炸 / 自行运动。

- 服务端：服务端每刻采集玩家附近 160 格内的实体真实状态（位置 / 速度 / 引信），经自定义网络包发给该玩家；客户端缓存后修正本地实体。默认关闭。

## 功能特性

本 mod 为客户端 mod，服务端可选安装，使用YACL进行配置：

- ✅ 弱加载区块 TNT 不再提前爆炸 / 自行运动。
- ✅ 弱加载区块实体分离渲染位置同步。
- ✅ F3+B 为 TNT 绘制动量箭头。
- ✅ 隐藏实体朝向箭头。
- ✅ 可在配置界面（ModMenu + YACL）开关。
- ✅ 精确显示爆炸粒子（可在配置界面关掉，退回原版那团随机粒子）。
- ✅ 关闭 TNT 闪烁与变大视效。
- ✅ 显示 TNT 剩余爆炸刻数标签。
- ✅ 修改渲染距离与模拟距离。
- ✅ 解除修改 Motion 的 ±10 限制。

### 支持的实体类别

| 类别     | 覆盖实体                                 |
| -------- | ---------------------------------------- |
| TNT      | `PrimedTnt`                              |
| 物品     | `ItemEntity`                             |
| 弹射物   | `Projectile` 子类（箭 / 珍珠 / 风弹 等） |
| 下落方块 | `FallingBlockEntity`                     |
| 经验球   | `ExperienceOrb`                          |

## 性能与已知限制

服务器同步每 tick 全量发送玩家周围指定实体信息（每实体约 65 字节）。
量级估算（每玩家、20 tps）：

- 单颗 TNT：约 1.3 KB/s，多玩家线性叠加。
- 作为对比，原版同步是相对增量 + 节流，同场景约为本 mod 的 1/10 到 0。
- tick sprint 时会暂停同步。

带宽只在专用多人服有意义，单人走 loopback，无真实网络消耗。
